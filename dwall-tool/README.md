# dwall
A tool for setting wallpaper using **dmenu** (wmenu or other)

Usage:
```
dwall - small tool for setting wallpaper
Flags:
	-i		set wallpaper
	-w		set wallpaper and generate palette with pywal
	-h		show ths help
```
Default tools:
```
awww
pywal16 (but you can use regular pywal ig)
```

Change `dwall.sh` to your system's tools (swww, matugen, wallust or etc)
